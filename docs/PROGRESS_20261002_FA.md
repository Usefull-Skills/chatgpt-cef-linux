# وضعیت مرورگر همراه Commander

کاندید همراه خواندنیِ مرورگر در PR شمارهٔ ۵۱ موجود است. افزونهٔ پایش جدید V03 اکنون به‌عنوان آرشیو سورسِ جدا و بدون تغییر مسیر اجرای اصلی منتشر می‌شود. هنوز مرورگر نهاییِ ویندوز یا ادامهٔ خودکارِ واقعیِ نشست چت تحویل داده نشده است.

## شواهد و محدودیت‌ها

کاندید قبلی commit `8e9e01e065d8b2e4ea07ce10d41738715ab5371b` یک پذیرش محدود Linux با ۷۶ آزمون داشته است. دو timeout مربوط به browser info نیز در شواهد آن باقی هستند؛ این پذیرش، ورود احرازشده، اجرای بلندمدت یا رفع خطای ChatGPT نیست.

سورس V03 برای تازه‌سازی پایش در پس‌زمینه و هنگام مخفی‌بودن پنل ساخته شده است. بررسی‌های ساختاری منبع، وجود guardها را بررسی می‌کنند؛ جای compile بومی، آزمون race، blocked I/O، مصرف حافظه، خروج در حالت pending یا اجرا روی دستگاه هدف را نمی‌گیرند. پذیرش نسخهٔ قبلی به V03 منتقل نشده است.

پنل فقط وضعیت مشاهده‌شده، تازگی داده و تطبیق هویت اعلامی را نشان می‌دهد. فهرست ابزارهای backend اثبات ابزارهای قابل‌فراخوانی همان چت نیست. دادهٔ نامعتبر، قدیمی یا متعارض، اختیار ادامهٔ خودکار ایجاد نمی‌کند.

## نقشهٔ راه

کاندید قبلی و سورس پایش V03 روی GitHub **← الان اینجاییم** → بررسی مستقل و compile با headerهای دقیق CEF → آزمون بومی refresh و hidden panel و shutdown → اتصال معتبر به میزبان و نشست مرورگر → آزمون Windows و Linux در دامنهٔ مجاز → اجرای بلندمدت و عدم تداخل → نصب با بازگشت → پذیرش نهایی.

مرحلهٔ انتشار از پذیرش عملیاتی جدا است. کل مرورگر: **NOT_FINAL**. فعلاً توسعهٔ فعال دستگاه هدف به سعید محدود است؛ این انتشار روی هیچ میزبان دیگری نصب نمی‌کند، عامل بازی یا ویدئو را فعال نمی‌کند و پیگیری خودکار لغوشده را برنمی‌گرداند.

## فایل‌های منتشرشده

پوشهٔ `experimental/companion-monitor-v03/overlay` فقط overlay منبع است، نه برنامهٔ مستقل یا دستور نصب. مسیرهای اصلی پروژه و CI بدون تغییر می‌مانند. manifest عمومی مسیر، اندازه و SHA-256 هر فایل و حدود بررسی منبع را ثبت می‌کند. تنظیمات و پروفایل مرورگر، اطلاعات ورود، چت واقعی و گزارش خام دستگاه منتشر نشده‌اند.

مرجع توسعهٔ backend: [Commander PR 99](https://github.com/GOD13emad/ChatGPTRemoteCommander/pull/99). این دو PR پیش‌نویس، محصول نهایی یا انتشار رسمی جدید نیستند.
